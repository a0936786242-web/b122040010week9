Lecture 02

二分搜尋法（Binary Search）

核心前提：資料必須先經過「排序（Sorted）」才能使用二分搜尋法，每次比較可排除一半的無效區間。

1. 演算法步驟

  • 設定左右邊界 left = 0 與 right = n - 1。
  • 計算中間索引 mid = left + (right - left) / 2（避免整數溢位）。
  • 若 arr[mid] == target，直接回傳索引；若小於目標則往右半邊找，反之往左半邊找。

2. C++ 實作模板

int binarySearch(vector<int>& arr, int target) {
    int left = 0, right = arr.size() - 1;
    while (left <= right) {
        int mid = left + (right - left) / 2;
        if (arr[mid] == target) return mid;
        else if (arr[mid] < target) left = mid + 1;
        else right = mid - 1;
    }
    return -1; // 找不到目標
}
