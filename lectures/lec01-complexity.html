Lecture 01

時間複雜度與 Big-O 漸近分析

學習目標：理解為什麼不用實際秒數評估程式效率，並學會計算基本迴圈的 Big-O 時間複雜度。

1. 什麼是 Big-O？

Big-O 用來描述當輸入資料量 n 變得非常大時，演算法執行次數的成長上限（Upper Bound），通常會忽略常數項與低次方項。

  • O(1)：常數時間，例如直接讀取陣列第 i 個元素。
  • O(log n)：對數時間，例如每次將搜尋範圍減半的二分搜尋。
  • O(n)：線性時間，例如走訪整個陣列一次。
  • O(n²)：平方時間，常見於雙層巢狀迴圈。

2. 程式碼範例分析

以下雙層迴圈中，外層執行 n 次，內層也執行 n 次，因此總執行次數為 n × n，時間複雜度為 O(n²)：

for (int i = 0; i < n; i++) {
    for (int j = 0; j < n; j++) {
        // 基本運算 O(1)
    }
}
